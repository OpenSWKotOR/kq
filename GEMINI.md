# Gemini CLI

Read and follow [AGENTS.md](AGENTS.md) before answering questions about this
repository or a KotOR install.

When the user asks what a creature, dialogue, 2DA, talk table, or script
contains, run `kq` (see AGENTS.md). Do not unpack `.bif` / `.mod` / `.rim`
files.

`-i` is `--install`. Case-insensitive search is `kq grep --ignore-case`.
